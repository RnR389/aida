# AidA Suchthilfe – Entwurf

Entwurf einer neuen Landingpage für A.i.d.A. e.V. (Selbsthilfe bei Alkoholproblemen) samt Website-Audit.

- Landingpage: `index.html`
- Audit der bestehenden Website: `audit/`

Statische Seite ohne Build-Schritt, Schriften lokal eingebunden, keine Cookies, keine Drittanbieter.
Die Seiten sind auf `noindex` gesetzt, solange es ein Entwurf ist.
